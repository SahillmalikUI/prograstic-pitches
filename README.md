# Prograstic Multi-Industry Pitch Engine

An engineering-led suite of dedicated outbound pitch landing pages for **Prograstic** ([prograstic.com](https://www.prograstic.com)), built on **Next.js 14+ (App Router)** and **Tailwind CSS**.

---

## 🚀 Live Industry Verticals

Each vertical is isolated and tailored to address **The Missing Loop** (operational bottlenecks) with custom software solutions, real-time prototypes, and direct discovery call scheduling:

* **Hospitals & Multi-Specialty**: `/hospitals`
* **Dental Practices & Multi-Chair Clinics**: `/dental`
* **Skin, Dermatology & Aesthetic Centers**: `/aesthetics`
* **Manufacturing & Industrial Operations**: `/manufacturing`
* **Orthopaedics, ENT & Specialized Practices**: `/clinics`
* **Overseas Education & Admissions Consultancies**: `/education`
* **Neurology & Diagnostic Imaging**: `/neurology`
* **IVF & Fertility Centers**: `/fertility`
* **Master Studio Hub**: `/`

---

## 🛠️ Tech Stack

* **Framework**: Next.js 14+ (App Router)
* **Styling**: Tailwind CSS & Prograstic Design System
* **Icons**: Lucide React
* **Deployment**: Optimized for Vercel

---

# Install dependencies
